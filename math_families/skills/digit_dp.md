当前运行边界（优先于历史库示例）：注册边界：只有当前请求列出的注册名称可调用；历史库层函数名不是 TOOL 名称。若当前运行明确提供 generated_python，可按独立协议在已接受 WASI 中探索，仅标准库、SymPy 1.12、mpmath 1.3.0；无宿主代码、网络、安装或跨题数据。提案不是执行，退出码0/PASS/NO_ISSUE不是数学证据；只有绑定回执后的结果才能消费，独立核验仍只授予指定输入/性质。缺少映射或范围依据不得改用 Python 绕过。

## 适用结构

题目要求统计满足以下约束的整数个数或首个反例：

- 十进制位属于给定数字集；
- 带模数/余数约束；
- 涉及数字和（digit sum）窗口性质的搜索；
- 删位整除链类递归约束。

## 需要提取的参数

- `digit_set`：允许的数字集合（0–9 的子集，非空）；
- `max_digits`：位数上限；
- `modulus` / `residue`：模数与目标余数；
- `include_zero`：0 是否计入（自然数约定差异在这里表达，不要事后 +1 补丁）。

## 推荐工具

- `count_by_digit_property`：位置 DP 计数，证书 = 逐长度计数表；
- `digit_sum_window_search`：滑窗模谓词首个反例，证书 = 窗口数字和（O(window) 可复验）；
- `deletion_divisible_largest`：删位整除链最大元，证书 = 完整删除链。

## 禁止使用的情况

- 题意不是按位约束计数/搜索时；
- 模数为合数时 digit_sum_window_search 不可用（逆元滑窗要求素数模）。

结构化参数的形式化；工具的计数结果不自动等于题目答案——单位元、空集、
"至多/恰好"的语义差异由你负责。
