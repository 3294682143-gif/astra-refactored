## 2. 内核必须保持的 16 项核心不变量（I01–I16）基准定义

在后续所有 PR（K01–K26）的抽取、重构与跨领域实现中，以下 16 项内核不变量必须全量保持不变：

* **I01 (输入可回溯)**：原始输入与来源严格保留，目标发生变更必须显式生成新版本（禁止模型私自增加有利假设）。
* **I02 (义务独立驱动)**：任务完成、候选产生、义务关闭分别记录，合法的回答不能自动关闭研究目标。
* **I03 (会话身份绑定)**：请求、任务、产物、证据强绑定同一运行与版本，严禁跨 run 窃用外部工具回执。
* **I04 (截断与未知防渗透)**：截断、错误和未知状态不得触发任何候选替换或外部工具调用动作。
* **I05 (根预算不可逃逸)**：所有工作、评审、重试、子任务均在同一预算树中统一记账，任何派生调用均受根预算与截止时间限制。
* **I06 (请求责任分离)**：未发送（本地拒绝）与已发送但结果未知（超时）分别记账，不制造虚假未决责任。
* **I07 (评审非证明)**：大模型评审或多数决仅作为“意见”，科学结论必须严格关联客观验证器回执。
* **I08 (证据范围限定)**：有限集合采样、数值仿真、统计结果仅在其声明条件与范围内有效，不可自动外推至全称结论。
* **I09 (版本失效传播)**：上游参数、假设或数据发生变更时，依赖图下游所有派生产物与报告自动标记为 `STALE`。
* **I10 (严格候选保护)**：父候选保留；新修复候选只有覆盖全部指明缺口且通过门控后才能进行版本替换。
* **I11 (否定候选禁止回退)**：被客观证据明确否定的父候选，严禁在后续修复失败时作为通过验收的结论交付。
* **I12 (外部效果幂等)**：重试、断线重连或事件回放不得重复触发具有副作用的真实外部计算。
* **I13 (隔离沙箱准入)**：外部代码与效果执行必须经过注册、参数校验与隔离沙箱，缺少隔离环境时直接报错，禁止回退到任意宿主执行。
* **I14 (诚实来源标识)**：执行结果必须显式区分 `live`、`replay` 与 `synthetic`，网络/模型失败时严禁用合成数据顶替。
* **I15 (数学接口兼容)**：数学对外接口 `candidate_verified=false` 恒为真，绝不将局部检查或选票多数决升级为整题绝对证明。
* **I16 (研究数据防御)**：输入的文献、论文或文本仅作为研究数据处理，其中的指令性词汇严禁越权修改系统的执行规则。

## 4. 行为样本索引（数学与通用控制场景）

为确保在内核抽取（K04–K08）过程中不破坏已有能力，建立以下行为样本索引作为等价性测试回归基准：

### 4.1 数学行为基准样本（Math Parity Suite）
1. **样本 M-01 (标准求解与单工具调用)**：
   - 输入：`求 GF(2) 上由 rows 表示的矩阵的秩，rows=[1, 2]`
   - 预期行为：M1 目标契约登记 → M2 准入许可 → 调用 `math.linear-algebra:gf2_rank` → 工具回执包含 `rank=2` → M5 候选生成，`candidate_verified=false`。
2. **样本 M-02 (拒止首次 unsolved 早退)**：
   - 输入：高难度不定方程问题
   - 预期行为：模型首轮返回 `unsolved` 时，控制层根据 `e062d7e` 规则强制先行拒绝一次，促使模型尝试调用可用数学资产。
3. **样本 M-03 (弃权强制取证)**：
   - 输入：含对称多项式问题
   - 预期行为：模型未直接生成候选时，触发 `ed55f74` 强制插入取证回合，调用 `use_math_asset` 进行代数化简。
4. **样本 M-04 (独立选票与全票审计)**：
   - 输入：多解集合问题
   - 预期行为：触发 `077f608` 独立多轮选票，在选票回合关闭思维链（`reasoning: false`），并在一致审计 `713f1c4` 满足后生成交付证书。

### 4.2 第二领域规划样本（Control Parity Suite, K11）
1. **样本 C-01 (受迫阻尼振子参数辨识)**：
   - 输入：时间序列激励 $u(t)$ 与位移响应 $x(t)$，前 80% 训练集，后 20% 验证集。
   - 预期行为：读取数据 → 识别单位与约束 → 调用最小二乘参数估计工具 → 获得质量、阻尼、刚度三参数 → 在后 20% 验证集上做独立前向预测计算残差。
   - 校验规则：若模型将后 20% 验证数据用于参数拟合，触发数据泄露 Challenge 并拒绝验收。
