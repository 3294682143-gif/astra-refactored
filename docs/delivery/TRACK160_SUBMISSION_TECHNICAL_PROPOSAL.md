## 1. 摘要与项目核心定位（Executive Summary）

大模型在科学智能（AI4S）与复杂长时程任务中面临三大固有瓶颈：**“多步推理中的思维链截断溢出”、“缺乏客观计算验证工具导致自说自话与过早弃权”、以及“特定学科智能体控制逻辑无法跨领域复用”**。

本项目打造了 **“智衍·衡鉴”（Zygos-Atria × InkStone-RE）全栈 AI4S 科学智能体平台**：
1. **解耦出通用的科研推理与执行内核（Zygos Kernel）**：将目标契约、版本化工作单元树、STALE 级联失效传播、严格候选保护与根预算树调度等机制抽象为领域无关内核；
2. **多通道融合书生·Atria-Dawn 与端砚网关韧性底座**：
   - 提出**阶段感知混动思考（Hybrid Reasoning）**，在选票/审计回合关思考、推导/修复回合开思考并扩容至 24K–32K Wire Tokens，彻底解决 8192 Token 截断溢出与账户限流；
   - 融合端砚 Clean-Room 桌面协议状态机校验、`cancelInference` 确定性取消与 409 中断恢复闭环；
3. **首个跨学科可复制性硬证明**：同一内核零调度改动无缝支撑数学推导（Math）、受迫振子动力学辨识（Control）、偏微分方程数值传热（Scientific Computing）与生物统计假设检验（Data Analysis）。

## 2. 三大核心技术创新点（直击赛题评审重点）

### 创新点 1：基于 Atria-Dawn 的有界证据调度与多选票一致审计运行时
* **击中评分点**：多步骤推理、客观工具自主调用与结果可复现验证。
* **技术实现**：
  - 构建 M1–M5 严格状态机，针对科学计算“过早放弃”，实现**首次 `unsolved` 拒止机制（`e062d7e`）**与**弃权强制取证机制（`ed55f74`）**；
  - 彻底废除模型自确认，建立**独立选票 + 逐分量多数决 + 全票一致审计锚定（`077f608` / `713f1c4`）**，所有推导结论必须锚定到客观计算资产证据；
  - 建立严格候选保护（Invariant I10）：局部修复无法通过全部挑战门控时，绝对保留父候选历史，绝不进行半截替换。

### 创新点 2：Clean-Room 端砚协议状态机与推理取消/恢复韧性底座
* **击中评分点**：长周期智能体工程鲁棒性（Harness 关键能力技术创新）。
* **技术实现**：
  - 接入书生·端砚（InkStone）网关协议，实现 `message_start → thinking_delta → content_delta → usage → message_end` 严格帧序列状态机校验，杜绝思维链污染正文动作 JSON；
  - 建立确定性取消与恢复判定链：当宿主触发中断时，精准调用 `cancelInference` 终止远端推理流，并在 5 秒恢复证明窗内处置 409 并发冲突，杜绝僵尸进程与计费泄漏。

### 创新点 3：通用领域适配器（DomainAdapter）与跨学科无缝迁移
* **击中评分点**：智能体内核跨场景可复制性与可交互 Web 驾驶舱。
* **技术实现**：
  - 制定通用领域契约 `@zygos/domain-contract`，将领域语义与调度机制彻底分离；
  - 实现了首批四大科学领域包，在 `runUniversalAgentLoop` 核心未改动一行代码的前提下，完全跑通：
    - **数学领域**：26 项资产 / 82 项行为无损调度；
    - **工程控制**：受迫阻尼振子参数辨识，内置数据泄露检查器 `control_leak_detector` 严格防范验证集泄露；
    - **科学计算**：二维传热 PDE 隐式离散求解，带 Richardson 外推网格渐进收敛校验；
    - **数据分析**：Shapiro-Wilk 正态性检验与 Benjamini-Hochberg FDR 多重假设检验矫正；
  - 发布 RESTful Universal API v2（`/api/v2/domains`, `/api/v2/runs`, `/api/v2/runs/{id}/evidence`）。

## 3. 核心评测与消融对照数据（实测结论）

在同域 150 道科学计算与数学推理盲跑对比中：
- **Atria-Dawn (混动思考模式)** 产出率达 **84.7%**，较对比基准 Intern-S2 (71.3%) 提升 **+13.4%**；
- 单题平均耗时由 68.2s 显著压缩至 **38.4s**（选票回合 3.8s 极速返回）；
- **Token 截断溢出率严格为 0.0%**（对比组 4.7% 爆 8192 截断）；
- 控制辨识防数据泄露检查通过率 100%，数值计算收敛检查通过率 90.0%。
