# 有限状态、动态规划与模状态组合

## 可观察产物

产出充分状态、初态、转移、终态及对象—路径无重无漏的对应。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件

所有影响未来合法性/代价的信息必须进入状态；状态域有限，或已有明确截断证明。

## 方法

1. 定义状态的数学含义，包含轮次、末端信息、资源量、余数等必要字段。
2. 从一个合法对象的唯一分解推出转移，区分计数加法、最优值比较和概率权重。
3. 给出初态、空对象及终态求和方式；初态不是凭记忆填1。
4. 模约束可作为状态分量，与局部禁配、生成自动机或转移矩阵组合。
5. DAG可拓扑递推；有环时不能把记忆化递归自动当成正确终止算法，需另用固定点/逆向分析等方法。
6. 状态压缩需证明被合并状态对未来等价。工具预算不足不允许静默丢状态。

## 产出与失败信号

输出状态定义、转移、边界与计数/最优性证明；算法返回值只认证这个状态模型。

## 验证

独立小规模枚举、递推不变量和另一种组合计数交叉检查，防止遗漏与重复。

## 正例与误用负例

正例：禁相邻1并限制1的数量模m时，状态包含末位与余数。
负例：只记录当前1的数量，丢掉末位，却声称仍能判断能否追加1。

## 绑定计算工具与精确调用契约 (Bound Registered Tools)

本节只列当前 P3 协议白名单（26 个注册算子）里本卡真正可调用的注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `bounded_enumeration`
- 何时用：在极小规模上核对状态模型的计数／最优化结果（终态聚合是否与手算一致）。
- `args` 模板：
```json
{"objects":[[0,0],[0,1],[1,0],[1,1]],"choose":2,"predicate":"count(0,1)==1"}
{"ranges":[2,2,2],"choose":2,"predicate":"count(0,1)<=1 and sum(2)==1"}
```
- 输入约束：`objects` 与 `ranges` 只能给一个；`choose` 取 1..6；对象 ≤ 60 行、每行 1..4 个 int/str 属性（同元数），`ranges` 为 1..4 个 1..60 的维度；组合总数 ≤ 5,000,000；`predicate` ≤ 400 字符，只能使用 distinct(i)/count(i,v)/size()/sum(i)/min(i)/max(i)/contains(i,v) 加算术比较与 and/or/not（索引从 0 开始）
- 输出边界：枚举只认证这个显式宇宙与谓词，不替你证明“题目对象 ↔ 属性表”的映射；小规模穷举不是无限族的证明。

### `transition_count`
- 何时用：显式状态集、有向转移与首末状态都已给定，需要精确数出长度为 L 的顶点序列数，或核对转移矩阵 DP 的终态求和。
- `args` 模板：
```json
{"length":3,"num_states":2,"transitions":[[0,1],[1,0],[1,1]]}
```
- 输入约束：`length` 为 1..6 的整数（表示顶点数，不是边数）；`num_states` 为 1..4；`transitions` 为 `[u,v]` 整数对且 `0<=u,v<num_states`（集合语义，重复边不计）；可选 `starts`/`ends` 为状态整数数组，默认全集时必须省略，禁止传 `null`。
- 输出边界：返回满足首状态属于 `starts`、末状态属于 `ends` 且每条相邻转移都在 `transitions` 中的序列精确总数；证书为末态 DP 向量，规模允许时附全枚举自检。只认证这份显式转移图，不认证题意到状态/边的映射。

### `independence_polynomial_chain`
- 何时用：需要路图 P_n 的独立集多项式 I(P_n,x) 或各阶独立集数目，核对 I(P_k)=I(P_{k-1})+xI(P_{k-2}) 的两步递推。
- `args` 模板：
```json
{"n":5}
```
- 输入约束：`n` 为 0..16 的非负 JSON 整数；不得引用题目序号或隐藏表。
- 输出边界：返回 I(P_n,x) 的系数列表，最高次项在前，第 k 项为 P_n 的 k 元独立集数；对指定 n 用全部子集精确枚举认证。它不证明通项公式，也不覆盖非路图结构。

### `count_by_digit_property`
- 何时用：按十进制数位集合、位数上限与余数条件做 digit DP 计数，并需要独立枚举校验。
- `args` 模板：
```json
{"digit_set":[1,2,3],"max_digits":3,"modulus":3,"residue":0,"include_zero":false}
```
- 输入约束：`digit_set` 为非空整数数组，元素均在 0..9；`max_digits` 为 1..3；可选 `modulus` 为 1..64（默认 1）、`residue` 为 0..modulus-1（默认 0）、`include_zero` 为 JSON 布尔值（默认 false）；不补前导零，零只由 `include_zero` 单独计入。
- 输出边界：返回位数不超过 `max_digits`、各位数字均属于 `digit_set` 且模 `modulus` 余 `residue` 的正整数精确个数；若 `include_zero` 且余数条件允许再额外加一。证书为各长度 DP 总计并附小规模暴力自检；不认证题意到数位约束的映射。
