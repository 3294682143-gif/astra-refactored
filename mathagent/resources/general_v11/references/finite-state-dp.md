# 有限状态、动态规划与模状态组合

## 可观察产物

产出充分状态、初态、转移、终态及对象—路径无重无漏的对应。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件

所有影响未来合法性/代价的信息必须进入状态；状态域有限，或已有明确截断证明。

## 方法

1. 定义状态的数学含义，包含轮次、末端信息、资源量、余数等必要字段。
2. 从一个合法对象的唯一分解推出转移，区分计数加法、最优值比较和概率权重。
3. 给出初态、空对象及终态求和方式；初态不是凭记忆填1。
4. 模约束可作为状态分量，与局部禁配、生成自动机或转移矩阵组合。
5. DAG可拓扑递推；有环时不能把记忆化递归自动当成正确终止算法，需另用固定点/逆向分析等方法。
6. 状态压缩需证明被合并状态对未来等价。工具预算不足不允许静默丢状态。

## 产出与失败信号

输出状态定义、转移、边界与计数/最优性证明；算法返回值只认证这个状态模型。

## 验证

独立小规模枚举、递推不变量和另一种组合计数交叉检查，防止遗漏与重复。

## 正例与误用负例

正例：禁相邻1并限制1的数量模m时，状态包含末位与余数。
负例：只记录当前1的数量，丢掉末位，却声称仍能判断能否追加1。
