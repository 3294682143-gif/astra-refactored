# 生成函数、系数提取与卷积

## 可观察产物

写出系数含义、生成关系和边界修正，再将所取系数对应回目标。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件
明确每个变量和系数的含义；区分普通生成函数、指数生成函数和概率生成函数。

## 方法
1. 从对象的独立组合/唯一分解推导加法、乘法与卷积，而不是因外形相似随意相乘。
2. 递推转函数方程时保留初值和所有边界修正项。
3. 只需固定系数时采用形式幂级数；讨论函数值、积分、换极限时另检查解析收敛域。
4. 多标签统计使用多变量；模约束可与有限状态或单位根过滤组合，说明过滤的正交关系。
5. 抽取系数后返回原对象含义，检查指数型中的阶乘因子。

## 产出与失败信号
输出生成关系、初始条件、目标系数与等价性。没有证明对象分解唯一时，系数可能计入重复或不合法对象。

## 验证
低阶展开与直接计数、代回递推。CAS截断阶只证明已算项；浮点单位根计算不能无误差界地四舍五入成精确计数。

## 正例与误用负例
正例：从给定生成函数按t提取t³系数，能用t导数在0处取值并除以3!核对。
负例：把形式级数恒等式直接在收敛半径外代入数值，仍宣称级数和相等。

## 绑定计算工具与精确调用契约 (Bound Registered Tools)

本节只列当前 P3 协议白名单（11 个注册算子）里本卡真正可调用的注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `polynomial_expand_coefficients`
- 何时用：把待展开（带参/多元）多项式变成完整有序系数表，用于核对生成函数的低阶系数与卷积。
- `args` 模板：
```json
{"expression":"(1+x+x**2)**3","variables":["x"],"parameters":[]}
```
- 输入约束：恰好这三个字段；`variables` 1..3 个主变量，`parameters` 为有序参数名（合计符号 ≤ 6）；表达式须为有理系数多项式：次数 ≤ 8、AST ≤ 256 节点、文本 ≤ 2000 字符、项数 ≤ 512；除法只允许除以非零常数。
- 输出边界：系数表只对这份表达式成立；“对象分解唯一”与系数含义仍需你证明。
