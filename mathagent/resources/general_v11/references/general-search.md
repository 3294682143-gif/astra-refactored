# 未匹配与换路

## 何时使用

目标清楚但没有可靠方法，或相同路线两次没有解决新义务。不要把“没选到卡”解释成题目无解。

目录不是能力白名单。可以使用未列入目录的方法；只需明确名称、前提、来源或自证依据及要完成的义务，不伪称读取了不存在的卡，也不扩大工具权限。

1. 保留原题，将目标重新表示为等式、集合、计数、可行性、优化或构造，标明输出映射。
2. 找最小非平凡规模、边界、零值和退化参数；用它们推翻猜想，不用“没找到反例”证明猜想。
3. 选择一个有依据的表示变化：状态/递推、双射、生成函数、坐标/向量、因式/模约束、对偶/反证、对称/换元。
4. 检查所需定理的条件。未知定理不得编造来源；可以直接补证明、明确作为条件，或报告缺口。
5. 下一次尝试必须改变关键表示、方法或被修正的假设。仅扩写同一路线不消除停滞。
6. 预算用尽时保存已证明事实、候选与最小未完成义务；没有证据则诚实返回未解决。

no_match 后要记录具体动作：直接求解、改变表示、提出目录外方法、请求关键条件，或依据预算返回未解决。不要仅反复改标签去强求某张卡命中。

失败摘要至少包含“失败义务 → 证据 → 被否定步骤 → 下一种改变”。如果只是某工具超时，保留数学路线尚未被反驳这一事实。

等价改写需要说明双向关系；加条件、求逆问题和参数化是新问题，不代替原题。

正例：直接数对象困难时，建立一一对应的状态路径，再证明转移无重无漏。

负例：有限搜索没有解就断言所有整数中无解，或把所求精确根换成未带误差界的近似根。
