# 定义域、等价变换与参数分类

## 可观察产物

列出原定义域、单向/双向变换和排除分支，给完整解集的逆向依据。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件

原式及变量域可保留，目标是原问题而非已约分/平方后的替代式。参数是否为零、符号、整数性必须明确或分支处理。

## 方法

1. 在变形前登记分母非零、根号、对数和分支条件；区分实数与复数约定。
2. 给变形标记“等价”或“仅推出”。乘除可能为零的式子，先拆零与非零分支。
3. 平方、取指数、消元或升次产生的是候选；回到原式核验。
4. 求完整解集时，另外证明每个原解都进入候选集。代回只能筛掉增根，不能证明没有漏根。
5. 参数改变次数、秩、定义域或区间端点时，先解决退化参数，再讨论一般情形。

## 产出与失败信号

输出带条件的解集或等价链。CAS返回条件集、未求解、超时不表示无解；若变形所需符号未确定，暂停该步而不是默认正数。

## 验证

检验原约束、被排除点、边界和逆向映射。近似残差小不自动证明精确成立，特别是病态或重根情形。

## 正例与误用负例

正例：解 sqrt(x+2)=x，先需 x≥0，再平方并筛选。
负例：把 sqrt(x²) 无条件写成 x；实数域一般应保留绝对值，复数域还涉及主值分支。

## 绑定计算工具与精确调用契约 (Bound Registered Tools)

本节只列本卡真正可调用的 P3 白名单注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `real_root_count_expr`
- 何时用：已把方程化成有理系数单变量多项式，需要不同实根的个数来决定分支（无实根／单根／重根）。
- `args` 模板：
```json
{"expression":"x**3-x-1","variable":"x"}
```
- 输入约束：`expression` 必须是多项式，不得先约去含变量的分母（含变量分母会被直接拒绝）；乘幂必须写 `**`（该族桥算子会拒绝 `^`）；次数 ≤ 6，系数分子/分母 ≤ 128；`variable` 可选（短标识符），`timeout_ms` 可选。
- 输出边界：计数只认证所给这个多项式；定义域与原方程解集是否一致仍由你论证。

### `exact_check_expr`（`operation` = `SIMPLIFY`）
- 何时用：核对“变形前后等价”这一步，取独立实现的化简式与零差证据。
- `args` 模板：
```json
{"operation":"SIMPLIFY","expression":"(x**2-1)/(x-1)","variable":"x"}
```
- 输入约束：`operation` 必填且只能取白名单枚举；`expression` 为白名单 AST 表达式字符串（≤500 字符，乘幂用 `**`，本算子也接受 `^`）；`variable` 为短标识符。
- 输出边界：零差只证明代数恒等，不证明定义域相同；被约去或被平方引入的点仍要单独登记。

### `solve_system_guarded_expr`
- 何时用：把已经写清的方程组交给独立求解，先拿到“隔离实解个数”，用来区分无解、有限解与参数族，再决定是否继续代数推导。
- `args` 模板：
```json
{"expressions":["x+y-3","x-y-1"],"variables":["x","y"]}
```
- 输入约束：`expressions` 必填，为 ≤ 6 条有理系数多项式字符串（乘幂写 `**`，`^` 会被归一化）；`variables` 必填，为 ≤ 3 个短符号名且顺序即列序；`timeout_ms`/`n_starts`/`seed` 可选。只认证两类系统：满秩仿射线性系统，或“每个变量各由一条单变量方程约束”的分离系统（单变量次数 ≤ 6）；耦合项、变量重复占用或秩不足的参数化系统超出审计范围。
- 输出边界：输出只是一个隔离实解个数（整数），证据等级至多 `NUMERICAL_SUPPORT`——不给出解的表达式，不覆盖自由参数族，也不证明你已把原方程等价变形到该系统。

### `polynomial_function_check`
- 何时用：候选解是显式有理多项式，要独立判定它是否满足一条“对所有变量都成立”的函数方程，并要精确残差或反例点。
- `args` 模板：
```json
{"equation":"f(x+y)=f(x)+f(y)","function":"f","argument":"x","variables":["x","y"],"expression":"x"}
```
- 输入约束：字段必须恰好是 `equation`/`function`/`argument`/`variables`/`expression` 五个（多一个或少一个都按 `invalid_input` 拒绝）；`equation` 必须恰好含一个 `=`，且 `f` 只用 `variables` 中的名字做自变量组合；`function`、`argument` 为短标识符且不得与 `variables` 重名；`variables` 为 1..3 个互异变量名；`expression` 必须是**只含 `argument` 一个变量**的有理多项式（出现别的变量会被判超出范围），次数 ≤ 12、≤ 128 个 AST 节点，只用整数或明确写出的分数。
- 输出边界：返回 `identity_holds` 布尔值、非零时的精确 `residual_terms` 与一个整数反例 `witness`（`point` 各分量绝对值 ≤ 12）；它只认证“这一个候选多项式”，不声称已求出全体函数解，也不替代唯一性论证。
