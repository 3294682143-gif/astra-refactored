# 同余、素数幂分解与广义CRT

## 可观察产物

作gcd相容性判别、局部解与合并模数检查，明确剩余类到整数域的映射。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件
区分全体整数解、模n的剩余类及指定区间内解。模数和因式分解必须合法。

## 方法
1. 以素因子/赋值把模条件拆成局部条件，写清分解的完整性。
2. 两个同余 x≡a(mod m)、x≡b(mod n) 可合并当且仅当 gcd(m,n)整除b-a；结果是模lcm(m,n)的类。
3. 两两互素时，局部解组合与模乘积的解存在CRT双射，才可乘数量。
4. 对 x²≡1 mod p^k，奇素数时利用 gcd(x-1,x+1)整除2说明只有±1；2的幂单独处理。
5. 将剩余类映射回所问区间，计算边界和代表元；整数全域通常得到无限算术级数。

## 产出与失败信号
输出相容性、合并类、模数与完整性依据。非互素不必无解，也不能无条件相乘局部计数。

## 验证
代回各同余、检查模lcm唯一性，小模数完整枚举。模幂的快速算法验证的是所给整数，不自动证明任意模数通式。

## 正例与误用负例
正例：模4余1与模6余3相容，可合并为模12的一个类。
负例：把奇素数幂“两类根”的论证用于模8；模8实际有四类平方为1的单位。

本节只列本卡真正可调用的 P3 白名单注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `solve_quadratic_diophantine`
- 何时用：已把整数不定方程整理成六项二次式 a x²+b xy+c y²+d x+e y+f=0，需要完整的整数解对集合，或要对已猜出的解族做独立代入复核。
- `args` 模板：
```json
{"a":1,"b":0,"c":1,"d":0,"e":0,"f":-25}
```
- 输入约束：`a`..`f` 六个必填且都为 JSON 整数（字符串、浮点、布尔一律拒绝），要求 `a != 0` 且各系数绝对值 ≤ 32；正定/负定形（`4ac-b²>0`）由审计自行取全局整数框，其余不定形必须显式给 `y_bound`（≤ 32），否则返回 `resource_limited`；直接枚举工作量上限 250000 次。
- 输出边界：结果是这份显式六项式的整数解对列表（每对为 `[x,y]`），不认证它就是你原同余问题的等价重写；不定形的解只在 `|y|<=y_bound` 内完备，框内无解不等于全域无解。

### `symbolic_diophantine_with_timeout`
- 何时用：方程仍是多项式表达式字符串（尚未拆成六项系数），且它是正定或负定二次型，需要一个有限整数解全集。
- `args` 模板：
```json
{"lhs":"x**2+y**2-25"}
```
- 输入约束：`lhs` 必填为多项式字符串（乘幂写 `**`，`^` 会被归一化）；`rhs` 可选，默认 `"0"`；`variables` 可选且恰为 2 个符号名，默认 `["x","y"]`；`timeout_ms` 可选。整系数 ≤ 32、次数 ≤ 2，且必须是正定/负定形；Pell 型、参数化或有理域解一律超出审计范围（返回 `resource_limited`）。
- 输出边界：输出是字符串整数对的有序列表，如 `[["-5","0"],…]`（字符串而非数字）；同样只认证这份显式方程，不证明原题已正确转写，也不覆盖无限解族。
