# 从原题到画像、选卡与换路

## 先读原题，再读目录

不要从一组熟悉标签反向改写题意。保留原文，将会影响答案的条件逐项标为 C1、C2……：对象/范围、目标、量词、端点、单位、抽样/等价约定、参数退化、明确排除及输出精度。

每项保留一句可定位的原文引文；由推导得到的条件另标 derived 并附依据。假设、未确认或矛盾条件不得混入“已知”。字符串引文匹配只证明文字存在，不证明它被正确解释，也不证明约束已列全。

目标是“计数某集合”时，先写这个集合的定义；目标是“所有解”时，先写论域和完整性要求。随后才添加任务、对象、结构等路由标签。

## 简短选卡记录

对实际采用的方法保留四项，不要求输出冗长思维日志：

- 本次要完成的步骤/障碍，例如“把局部限制编码成充分状态”。
- 支持这个方法的具体条件ID及一句理由。
- 尚未确认的定理前提或建模条件，不能只写“看起来适用”。
- 预期产物，例如状态与转移、双射、参数分支、全域下界和取等点。

如果卡没有帮助推进上述产物，记录“无具体增益”，而不是因读过就计成功。

## 失败驱动换路

记录：哪项义务失败、实际证据是什么、否定了哪个假设/步骤、下一次改变哪种表示或方法。失败证据可以是合法反例、代回不满足、遗漏边界、独立审查发现漏条件或实际工具故障。

工具超时只说明执行未完成，不反驳数学方法。相同答案、更多文字或自报更自信不是新证据。

## no_match 与目录外方法

按顺序检查：是否标签写法不一致；是否已存在直接解法；是否需要不同表示；是否可以使用已掌握但未入库的方法。记录目录外方法名称、使用理由、前提和要验证的义务，不把它伪装成已加载卡。

无需先为目录外方法新建skill，也不应强行套最近的卡。外部定理来源不确定时补证明、给条件化结果或保留未解决；不编造来源，不擅自联网/安装依赖。

## 画像如何验收

应让审查者先只看原文，独立提取目标和约束，再与求解者的画像比较。至少检查遗漏、额外假设、量词/范围改变和当前障碍是否真实。

评测从陌生原题开始，不预先给正确标签。统计约束召回/错误添加、目标误读、选路依据是否成立、未知前提是否保留、卡是否完成具体步骤，以及无匹配后能否继续或合理停机。标签排序测试不能代替这些语义评测。

脚本 reasoning_contracts.py 仅能查记录结构、引文、对应项及审查记录绑定；“画像语义正确”仍需真实的独立数学审查。

## 结构化记录示例

以下只是记录格式，不是已审核的数学证据：

    {
      "problem_id": "example-only",
      "original": "求0≤x<45中满足x²≡1(mod45)的整数个数。",
      "goal": "计数指定区间中的全部整数解",
      "constraints": [
        {"id":"C1","statement":"x是整数","origin":"explicit","source_quote":"整数"},
        {"id":"C2","statement":"0≤x<45","origin":"explicit","source_quote":"0≤x<45"},
        {"id":"C3","statement":"平方同余条件","origin":"explicit","source_quote":"x²≡1(mod45)"}
      ],
      "ambiguities": [],
      "tasks": ["count"],
      "objects": ["integer","congruence"],
      "structures": ["modular_constraints"],
      "current_obstacle": "尚未给出所有剩余类的完整性论证",
      "selection_notes": {
        "modular-crt": {
          "supports": ["C2","C3"],
          "why": "局部同余可组合回一个完整剩余系",
          "unconfirmed": ["素数幂分解与局部解完整性"],
          "expected_step": "建立局部解组合与全体剩余类的双射"
        }
      }
    }

failure_evidence 中可记录 method_id、obligation、observation、evidence_ref、next_change。另有未入目录方法时，用 external_methods 的 name、rationale 记录，不虚构文件路径。标签仍可作为轻量召回输入，但缺失这类原文依据时必须保留“画像未核验”的状态。
