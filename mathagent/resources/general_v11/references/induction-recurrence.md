# 归纳、递推与良基结构

## 可观察产物

写全基例、依赖次序和归纳闭合步骤，核对初值是否唯一确定递推对象。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件

索引范围、初值和递推适用起点明确；递归依赖必须落在较小对象或良基序上。

## 方法

1. 按命题结构选择普通、强归纳或结构归纳，不把所有归纳都机械设成一步。
2. 列出覆盖起始范围所需的全部基例，检查递推在边界是否需要额外初值。
3. 递推建模先证明对象分解无重无漏，再求通项、生成函数或渐近式。
4. 线性递推求特征根时保留重根的多项式因子；非齐次项共振时修正特解形式。
5. 验证候选满足初值与递推，并说明唯一性，不能只拟合前若干项。

## 产出与失败信号

给出基例、归纳假设、合法的归纳步及参数范围。缺少初值可能意味着多个序列，不擅自选一个。

## 验证

小规模计算用于查错；证明递推本身和求解递推是不同义务。

## 正例与误用负例

正例：二阶递推先固定两个独立初值，再由递推唯一决定后续项。
负例：观察到前五项是平方数，就断言所有后续项必为平方数。

## 绑定计算工具与精确调用契约 (Bound Registered Tools)

本节只列当前 P3 协议白名单（11 个注册算子）里本卡真正可调用的注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `bounded_enumeration`
- 何时用：只作小规模基例与低阶递推的数值核对（前若干项、边界项是否满足候选通项）。
- `args` 模板：
```json
{"ranges":[5,5],"choose":1,"predicate":"sum(0)*sum(0)==sum(1)"}
{"objects":[[0,1],[1,3],[2,9]],"choose":2,"predicate":"count(0,2)==1"}
```
- 输入约束：`objects` 与 `ranges` 只能给一个；`choose` 取 1..6；对象 ≤ 60 行、每行 1..4 个 int/str 属性（同元数），`ranges` 为 1..4 个 1..60 的维度；组合总数 ≤ 5,000,000；`predicate` ≤ 400 字符，只能使用 distinct(i)/count(i,v)/size()/sum(i)/min(i)/max(i)/contains(i,v) 加算术比较与 and/or/not（索引从 0 开始）
- 输出边界：枚举只认证这个显式宇宙与谓词，不替你证明“题目对象 ↔ 属性表”的映射；小规模穷举不是无限族的证明。
