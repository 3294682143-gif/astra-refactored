# 代数结构归约：选择检查对象并产生证书

## 成立条件
这是决策卡，不是“覆盖整个抽象代数”的承诺。先固定目标对象及约定，再只执行相关分支：群的表示与阶；环是否交换/含幺；同态是否保幺；多项式底域。

## 方法

| 当前目标 | 先作的具体决策 | 下一步与必须产出的对象 |
|---|---|---|
| K[x]/(p) 中求逆，K为域 | p、代表多项式、取模是否定义正确？不能先假定商为域 | 算gcd；若为1，给Bezout等式与次数约化后的逆元，验证乘积余式为1 |
| 理想的像/原像或商环性质 | 目标是f(R)还是整个余域？是否保幺/交换/满射？ | 检查吸收性与真理想条件；主理想整环先排零因子，再证明主性 |
| 有限群共轭类 | 采用哪个群作用？母群的类在子群中可能分裂吗？ | 给代表元、中心化子、轨道大小，核对类的划分与大小总和 |
| 分裂域或生成域的次数 | 候选只是含全部根，还是由根生成的最小域？ | 列根/必需根之比，给双向包含；再给逐级最小多项式或交域依据 |

同构归约须交付良定义与逆映射/核像的证据。出现可能为零的参数、变次数或变秩时，把该分支从一般情形中分出。

## 具体产物

只选一条相关分支，交付“结构约定 → 归约对象 → 可检查证书 → 尚缺的最小性/完整性理由”。如果本卡只提示了“去用某个定理”，却没有帮忙完成这一步，记录无具体增益，改用目录外专门方法，不继续堆叠抽象名词。

## 产出与失败信号
仅验证了有限实例时，不提升成无限族分类。系数环不是域、对象不是单多项式商时，不机械套gcd判据；原像包含单位元时，不把它称为真素理想。

## 验证
逐项核对所选分支的证书是否回答原目标。CAS在某底域因式分解或给出一个较大生成域，不证明题目要求的最小次数。

## 正例与误用负例
正例：两个互素多项式因子的商可用中国剩余定理识别为直积，从而检验零因子。
负例：α=aζ 属于分裂域就断言a和ζ分别属于该域，进而虚增扩张次数。

## 绑定计算工具与精确调用契约 (Bound Registered Tools)

本节只列当前 P3 协议白名单（11 个注册算子）里本卡真正可调用的注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `splitting_field_degree_expr`
- 何时用：判断分裂域相对底域的次数（是否不可约／是否完全分裂），为“最小生成域”分支取证。
- `args` 模板：
```json
{"expression":"x**3-2","variable":"x"}
```
- 输入约束：乘幂写 `**`（该族桥算子拒绝 `^`）；单变量有理系数多项式，次数 ≤ 3；走有理根检验与判别式平方类，不做本原元求解；`variable`、`timeout_ms` 可选。
- 输出边界：只认证所给多项式的次数；`aζ ∈ K` 不能拆成 `a, ζ ∈ K`。

### `finite_group_structure`
- 何时用：把显式置换生成元或闭集命名群算成阶、元素阶分布与共轭类，核对“共轭类划分与大小总和”。
- `args` 模板：
```json
{"generators":["(12)","(123)"],"degree":3}
{"named_group":"A4"}
```
- 输入约束：两种形态只能给一种：`generators` 为 1..4 个同一度数的互不相交轮换写法的生成元、`degree` 取 2..8；或 `named_group` 取闭集命名群 S3/S4/A4/A5/D8/D10/Z2..Z12/C2..C12；闭包 ≤ 600 个元素。
- 输出边界：只做子群记账，不判断题目要的是母群还是子群，也不是同构分类的证明。

### `exact_check_expr（`operation` = `FACTOR_OVER_EXTENSION`）`
- 何时用：给定显式极小多项式后，判断目标多项式在该扩张上是否完全分裂。
- `args` 模板：
```json
{"operation":"FACTOR_OVER_EXTENSION","expression":"x**3-2","variable":"x","minimal_polynomials":["x**3-2"]}
```
- 输入约束：`minimal_polynomials` 给 1..4 个同变量、正次数多项式，总体次数 ≤ 12；矩阵以外的字段不得混用。
- 输出边界：返回各因子次数与 `splits_completely`；扩张是否最小、次数是否最小仍需你另证。
