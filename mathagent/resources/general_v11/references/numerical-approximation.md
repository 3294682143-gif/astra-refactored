# 近似、误差传播与稳定性

## 可观察产物

分清误差来源、条件性与算法稳定性，给需要证明的误差界或已知可靠范围。 若本次没有推进这一步，记录“未观察到具体增益”，不按读取次数计有效。

## 成立条件
明确绝对/相对误差、输入精度、目标容差及域；精确结论不能被未标误差的小数替代。

## 方法
1. 区分问题条件数与算法稳定性。相对传播 |xf′/f| 需分母有意义，零值附近另看绝对误差。
2. 插值先要求节点和数据一致；节点重复需合并或导数约束。精确过节点不代表区间误差小。
3. 等距高次插值可能出现Runge现象；Newton与Lagrange只是同一插值多项式的不同表达。
4. 差分/Euler/有限元等先定义离散对象和边界，再核对一致性、稳定性与适用收敛定理。局部与全局误差阶不同。
5. 多精度或步长加密用于查错，但误差比稳定不自动给严格误差界。
6. 迭代停机同时检查残差与条件性；舍入误差、截断误差和建模误差分开。

## 产出与失败信号
给近似值、误差定义、可靠数字及未证明范围。NaN、溢出、消减或不收敛应明确报告。

## 验证
用解析界、区间包围或独立算法；浮点秩/相等判断必须披露容差。

## 正例与误用负例
正例：Euler一步来自一阶Taylor，足够正则时局部误差与全局误差按不同阶估计。
负例：解线性系统残差很小就断言解误差很小，忽略病态矩阵。

## 绑定计算工具与精确调用契约 (Bound Registered Tools)

本节只列当前 P3 协议白名单（26 个注册算子）里本卡真正可调用的注册工具。工具只对显式输入重算一次精确结果并给独立校验，不判定“题目→输入”的映射是否正确，也不替代原题的证明义务。

### `interpolation_fit_check`
- 何时用：核对候选插值多项式是否精确过给定节点，并取精确残差与独立求出的插值多项式。
- `args` 模板：
```json
{"points":[{"x":"0","y":"1"},{"x":"1","y":"4"},{"x":"2","y":"9"}],"expression":"x**2+2*x+1","variable":"x"}
```
- 输入约束：`points` 给 2..8 个互异的精确有理数节点（字符串）；`expression` 次数 ≤ n−1 ≤ 7、分子/分母 ≤ 10^6；恰好这三个字段。
- 输出边界：残差全零只说明精确过节点，不说明区间误差界，也不排除 Runge 现象或舍入放大。

### `finite_difference_derivative`
- 何时用：需要中心/向前/向后差分给出 f′(x) 的数值估计，并查看步长减半的 Runge 误差估计与收敛比。
- `args` 模板：
```json
{"f":"x**3","x":1.0,"h":0.01,"method":"central"}
```
- 输入约束：`f` 为仅含 x 的标量数学表达式字符串（有界 AST）；`x` 满足 |x|≤100；`h` 满足 1e-6≤h≤1；可选 `method` 为 `central`、`forward` 或 `backward`（默认 `central`）。输入必须给 JSON 数值，不能把数字写成字符串。
- 输出边界：返回步长 h 下的差分估计值；独立检查按 1e-7+1e-8 相对容差重算，并附采样表、半步收敛比与经验 Runge 界。它是数值近似，不认证导数真值，也不自动给出严格误差上界。

### `richardson_extrapolate`
- 何时用：在已有差分估计上做一层 Richardson 外推，消去指定阶的首项截断误差并比较粗细外推值。
- `args` 模板：
```json
{"f":"x**3","x":1.0,"h":0.01,"method":"central","order":2}
```
- 输入约束：`f`、`x`、`h` 与有限差分相同；可选 `method` 为 `central`/`forward`/`backward`（默认 `central`），可选 `order` 为 1..8 的整数（缺省取方法的规范阶）。
- 输出边界：返回细步长侧外推值 R_fine；独立检查重算同一外推组合，并以 |R_fine−R_coarse| 作经验误差。它不认证截断误差阶、收敛性，也不能把数值外推当成解析导数证明。
