# transfer_matrix — 操作流程

## 1. 识别信号

有限链/带状计数、显式状态转移、路径独立集多项式和小网格哈密顿计数。无有限归约的二维问题不直接套用。

## 2. 建模前提

证明计数对象与状态序列的对应，明确首尾条件、重复计数约定、状态数和推进长度；完整保留转移。

## 3. 后端选择

transition_count、independence_polynomial_chain、hamiltonian_paths_grid按当前有界接口优先。需构造不同有限图并组合DP可用generated_python；不能把既有网格资源拒绝改称相同独立认证的Python路径。

## 4. 完整提案示例

TOOL: independence_polynomial_chain; INPUT: {"n":4}; PURPOSE: 计算P4各大小独立集数量; DOMAIN: 四个有序路径顶点; MAPPING: 合成例只有相邻顶点连边，完整对应注册路径图

## 5. 消费结果

按接口约定读取系数顺序，回执后检查计数/边界；独立核验的是显式有限图。DP成功不证明模型忠实，也不证明全部长度上的公式。

## 6. 失败处理

状态爆炸拆分有界任务并保留原预算；缺首尾或图映射先推理；超限不截断状态后声称穷尽。注册边界：只有当前请求列出的注册名称可调用；历史库层函数名不是 TOOL 名称。若当前运行明确提供 generated_python，可按独立协议在已接受 WASI 中探索，仅标准库、SymPy 1.12、mpmath 1.3.0；无宿主代码、网络、安装或跨题数据。提案不是执行，退出码0/PASS/NO_ISSUE不是数学证据；只有绑定回执后的结果才能消费，独立核验仍只授予指定输入/性质。缺少映射或范围依据不得改用 Python 绕过。
