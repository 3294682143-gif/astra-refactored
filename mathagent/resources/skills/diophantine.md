# diophantine — 族指导（模型可见输入）

当前运行边界（优先于历史库示例）：注册边界：只有当前请求列出的注册名称可调用；历史库层函数名不是 TOOL 名称。若当前运行明确提供 generated_python，可按独立协议在已接受 WASI 中探索，仅标准库、SymPy 1.12、mpmath 1.3.0；无宿主代码、网络、安装或跨题数据。提案不是执行，退出码0/PASS/NO_ISSUE不是数学证据；只有绑定回执后的结果才能消费，独立核验仍只授予指定输入/性质。缺少映射或范围依据不得改用 Python 绕过。

## 适用结构

低次丢番图方程：二次型因式分解、判别式平方族、有界精确扫描、
回代证书。

## 需要提取的参数

- `solve_quadratic_diophantine`：一般二次六项系数 a..f（方程
  a x² + b xy + c y² + d x + e y + f = 0）、可选 y 界；
- `solve_quadratic_discriminant_family`：判别式多项式系数 c2/c1/c0
  与 x 范围；
- `verify_quadratic_solutions`：系数 + 候选点列表（纯验证）；
- `symbolic_diophantine_with_timeout`：字符串方程（白名单校验后
  符号求解，带超时）。

## 推荐工具

见上。每个解附带回代验证；扫描证书注明范围。

## 禁止使用的情况

- 无界 Pell/Thue/高次方程的完备性宣称——有界扫描之外需要专门理论，
  本族 partial 状态就卡在这里；
- 把有限扫描当成全体解的证明。

## 证据完备性要求

回代验证每个报告解是精确的；"无其他解"只在扫描范围内成立。
无穷族（如参数族）必须由恒等式代入验证 + 族外无其他解的论证组成。

## 需要模型自行证明的部分

参数族完备性（族外无解）与范围界（为什么只需要扫到这里）。
