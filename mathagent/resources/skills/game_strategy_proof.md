# game_strategy_proof — 族指导（模型可见输入）

当前运行边界（优先于历史库示例）：注册边界：只有当前请求列出的注册名称可调用；历史库层函数名不是 TOOL 名称。若当前运行明确提供 generated_python，可按独立协议在已接受 WASI 中探索，仅标准库、SymPy 1.12、mpmath 1.3.0；无宿主代码、网络、安装或跨题数据。提案不是执行，退出码0/PASS/NO_ISSUE不是数学证据；只有绑定回执后的结果才能消费，独立核验仍只授予指定输入/性质。缺少映射或范围依据不得改用 Python 绕过。

## 适用结构

大棋盘/无限/持久博弈：需要配对、势函数或不变量策略证明。
本族只验证证书，不直接求竞赛题答案。

## 需要提取的参数

- `pairing_strategy_verify`：元素集、配对照（fixed-point-free 对合）、
  威胁集族（每个威胁集必须含完整一对）；
- `independent_reply_certificate`：元素集 + 冲突对；
- `potential_function_check`：初态、迁移关系（库层 callable）、
  势函数与模式（constant/nonincreasing/bounded）；
- `small_board_scan`：尺寸序列 + 博弈构造器（库层 callable）。

## 推荐工具

见上。配对证书的验证是全量机械的；小棋盘扫描表标注猜想级。

## 禁止使用的情况

- 把小板扫描表当成大棋盘结论；
- 势函数只在采样边上检查——本工具是全量 BFS，但仍限于可达预算内。

## 证据完备性要求

证书验证通过 ≠ 策略存在性全自动：你要先提出候选配对/势函数。
工具回答的是"这个证书对不对"，不是"证书是什么"。

## 需要模型自行证明的部分

候选策略的构造本身；无限/大棋盘从证书到定理的包装论证。
